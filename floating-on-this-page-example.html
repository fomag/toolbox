About This Component

The "On This Page" navigation component provides users with a quick way to jump to specific sections on a long-form page. This enhanced version is even smarter—it starts at the top of the page content, giving users an immediate overview of what's on the page. Once they begin scrolling down, the navigation intelligently moves to the right side of the screen where it floats, staying visible and accessible without taking up valuable space at the top.

This example uses real content from the Canada Revenue Agency website to demonstrate how the component works in a real-world scenario. The navigation automatically highlights the section the user is currently viewing, providing visual feedback about their position on the page.

Social Insurance Number (SIN)

A Social Insurance Number (SIN) is a nine-digit number that you need to work in Canada or to receive benefits from the Government of Canada. It is issued by Employment and Social Development Canada (ESDC). Your SIN is confidential and you should never share it unnecessarily.

Why you need a SIN

You need a SIN to:

  • Work in Canada
  • Open a bank account
  • Apply for a loan or credit card
  • Apply for government benefits
  • Report income and file income taxes
  • Register for the Canada Pension Plan (CPP)
  • Register for Employment Insurance (EI)

How to get a SIN

If you are a Canadian citizen, permanent resident, or refugee, you can apply for a SIN. To apply, you will need to:

  • Complete the Application for a Social Insurance Number form (Form SIN Application)
  • Provide proof of identity and residency in Canada
  • Submit your application in person at a Service Canada office or by mail

Types of SINs

There are different types of SINs depending on your status in Canada:

  • Regular SIN: Issued to Canadian citizens and permanent residents who are authorized to work in Canada
  • Temporary SIN: Issued to foreign workers and international students who are authorized to work or study in Canada

Protecting Your SIN

Your SIN is sensitive personal information. You should protect it from theft or misuse by:

  • Never sharing it unless absolutely necessary
  • Not writing it on cheques or postcards
  • Safely storing documents that contain your SIN
  • Shredding documents before discarding them
  • Being cautious of phishing emails or calls requesting your SIN

Employer Responsibilities

As an employer, you must request a SIN from each employee. You need the SIN to:

  • Deduct income tax, Employment Insurance (EI), and Canada Pension Plan (CPP) contributions
  • Report employment income to the Canada Revenue Agency
  • Issue a T4 slip at the end of the year

Requesting a SIN from an Employee

You must request a SIN from each employee before or when they start working. You can request this information on an application form or other document. Once you have collected the SIN, you must:

  • Keep it confidential
  • Store it securely
  • Only use it for employment-related purposes
  • Protect it from unauthorized access

Verifying a SIN

You can verify that a SIN is valid using the Social Insurance Number Validation application. This service allows you to confirm that an individual's SIN matches their name and date of birth. Note that this service does not confirm employment authorization.

Technical Implementation

This floating navigation component uses a combination of CSS and minimal JavaScript. The navigation starts at the top using standard positioning, then intelligently transitions to a fixed right-sidebar position when the user scrolls down. This smart behavior provides the best of both worlds: immediate visibility at the top of the page, plus persistent accessibility while scrolling.

How It Works

The component uses JavaScript to detect when the user has scrolled past the initial content. Once scrolling begins, the navigation switches from relative positioning to fixed positioning on the right side. CSS classes handle the styling transitions, ensuring a smooth visual change. Anchor links continue to work seamlessly throughout.

CSS Requirements

To implement this component, you need:

  • Two CSS class states: one for top positioning, one for right-side positioning
  • Fixed positioning with calculated right value to stay within container
  • Smooth transitions between states
  • Responsive design to hide on smaller screens when fixed

JavaScript Requirements

Minimal JavaScript is needed to toggle between positioning states and calculate the proper right offset. The script:

  • Listens for scroll events
  • Determines when to switch between top and right positioning
  • Calculates the correct right offset based on container position
  • Toggles CSS classes to apply the appropriate styling
  • Tracks the currently active section for highlighting

Best Practices

When implementing a dynamic floating "On This Page" navigation, consider these guidelines:

  • Use clear, descriptive h2 headings: The navigation is only useful if headings accurately describe section content
  • Limit sections: Aim for 5-10 main sections to avoid overwhelming the navigation
  • Smart positioning: Start at the top for immediate visibility, move to the side when scrolling begins
  • Container-aware: Keep the navigation within container bounds, not floating outside
  • Responsive behavior: Hide the fixed version on mobile to preserve screen space
  • Accessibility: Use semantic HTML headings and proper link anchors
  • Visual feedback: Highlight the current section to help users orient themselves
  • Smooth transitions: Use CSS transitions to make position changes feel natural
